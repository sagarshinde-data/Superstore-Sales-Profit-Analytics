# Superstore-Sales-Profit-Analytics
Data Analytics Project using Excel, MySQL, Python and Power BI

## Project Overview
This project analyzes Superstore sales, profit, customer performance, and business trends 

## Tools & Technologies
- Microsoft Excel
- MySQL
- Python (Pandas, NumPy, Matplotlib)
- Power BI
- Power Query
- DAX

## Project Workflow
1. Data Cleaning using Excel
2. Business Analysis using MySQL
3. Exploratory Data Analysis (EDA) using Python
4. Interactive Dashboard Creation using Power BI

## Key Analysis
- Sales and Profit Analysis
- Category-wise Sales
- Region-wise Performance
- Top 10 Customers and Products
- Monthly Sales Trends
- Discount vs Profit Analysis
- Shipping Time Analysis
